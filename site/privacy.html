店管管 隐私政策

{{COMPANY_LEGAL_NAME}}（下称"我们"）运营 店管管（域名 {{SERVICE_DOMAIN}}，下称"本服务"）——一个面向跨境电商卖家的 AI 运营 SaaS，功能覆盖选品、Listing 生成、广告分析、智能客服、竞品监控与素材生成。

我们深知个人信息对你至关重要，并会尽力保护其安全可靠。我们致力于维持你对我们的信任，恪守以下原则保护你的个人信息：权责一致、目的明确、选择同意、最少够用、确保安全、主体参与、公开透明。

请在使用本服务前，仔细阅读并理解本政策。若你不同意，请勿使用本服务。

一、本政策适用范围

本政策适用于本服务官网、Web 应用、以及我们通过 API 或浏览器扩展提供的相关功能。不适用于由第三方独立运营的服务（例如你自行开通的 Amazon / Shopee 卖家后台），也不适用于我们已另行约定数据处理协议的客户数据委托处理场景（见第十一节）。

三、我们如何使用这些信息

我们仅在下列目的与法律依据范围内使用收集的信息：

  1. 提供与履行服务（履行合同所必需）：账号与登录、店铺数据同步、AI 功能调用、 结果展示与导出、订阅与账单管理；
  2. 保障安全（履行法定义务 / 保护重大合法权益）：账号防刷、异常登录拦截、 操作审计与留存期清理；
  3. 改进产品（基于合法利益，且以去标识化/聚合形式进行）：功能使用统计、 错误诊断、性能优化；
  4. 与你就服务进行沟通：服务通知、安全提醒、账单与到期提醒、 以及在你同意的前提下的产品动态。

我们不会将你的个人信息用于自动化决策且对你有重大影响的情形；若未来引入此类处理，我们会事先告知并提供拒绝/人工干预的途径。

当前不涉及个人信息出境。 本服务所选用的第三方服务（阿里云百炼 DashScope、阿里云邮件推送 DirectMail、支付宝）均部署于中华人民共和国境内，个人信息在境内处理与存储。若未来因更换服务商或调整部署而需要将个人信息传输至境外，我们将在传输前履行法定程序（标准合同 / 安全评估 / 个人信息保护认证 之一），更新本政策，并向你告知接收方与传输路径。

七、我们如何保护信息

  1. 加密：店铺授权凭据等敏感字段采用对称加密后落库；传输采用 HTTPS。
  2. 访问控制：多租户隔离——你的数据按账户/店铺归属过滤，其他租户无法访问； 后台能力对内部人员按最小权限授予。
  3. 审计与监控：关键写操作留痕；运行指标与告警覆盖接口错误率、依赖可用性、 后台清理任务是否按时执行。
  4. 备份：数据库每日备份并做完整性校验与恢复演练。

尽管我们采取上述措施，互联网环境并非绝对安全。若发生个人信息安全事件，我们将按法律要求及时以邮件/站内通知等方式告知你可能受到的影响及已采取的处置措施。

我们使用 Cookie / 本地存储以维持登录态、记住界面偏好与主题设置、以及保障安全（例如防止跨站请求伪造）。你可通过浏览器设置管理或清除 Cookie，但这可能导致部分功能不可用。

十、语音克隆的特别说明

"语音克隆"功能会处理你的声音（生物特征相关信息）。该功能默认关闭且必须经你单独、明确同意后方可启用；启用前你需确认你已取得该音色权利人的授权。你可随时在功能面板中删除已克隆的音色；删除后我们不再持有该音色样本。请勿在未获授权的情况下克隆他人声音，或将克隆音色用于误导、欺诈或违法用途。

十一、企业客户与委托处理

当你以企业客户身份使用本服务，且你通过本服务处理你自身客户的个人信息时，我们通常作为受托处理者、你作为个人信息处理者。此时我们将：按你的指示处理、不超范围使用、协助你响应数据主体请求、并在你终止使用后按 data-processing-agreement.md 删除或返还数据。

十二、未成年人

本服务面向企业用户与专业人员，不面向未成年人。我们不主动收集未成年人个人信息；若发现误收集，将尽快删除。

十三、本政策的变更

我们可能适时更新本政策。对于重大变更（例如新增数据类别、改变共享对象、延长留存期），我们将通过站内通知或邮件提示，并在必要时重新取得你的同意。变更后的政策自发布之日起生效。
