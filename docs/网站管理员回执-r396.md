## 三个坑（都会静默失败）

1. **漏传 mp4**：页面其余部分完全正常，只有点播放才 404。
   建议验收脚本显式列 11 个路径逐件 curl，而不是"`assets/` 目录存在即通过"。
2. **服务器不返回 `Accept-Ranges`**：视频能播，但**拖进度条无效**、跳转要等整段下完
   （5 MB）。nginx 默认支持 Range，但如果这一层前面有其它代理/缓存、或对 mp4 做了
   改写，会丢。第 17 条就是查这个。
3. **`Content-Type` 不是 `video/mp4`**：Safari 会拒绝播放（Chrome 能容错）。
   nginx 的 `mime.types` 一般没问题，但自定义 location 里 reset 过类型的话要补。

## 两个设计取舍（如果你方复审时有疑问）

- **不放首屏**：5 MB 视频会顶掉 LCP。用 `preload="none"` + `poster` + `aspect-ratio`，
  首屏不拉视频流、版面也不跳。页面**没有** `autoplay`。
- **没有字幕轨**：成片已把字幕烧进画面（发到简历链接/微信/邮件也保得住）。
  UI 再挂 `kind="captions"` 就是两层字幕叠在同一屏（实测截图里同一句话出现两次）。
  无障碍改用 `<details>` 全文文字稿（零 JS、可复制可搜索），`ST20` 会把"加回字幕轨"判成 FAIL。
