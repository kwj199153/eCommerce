## 一、本政策适用范围

本政策适用于本服务官网、Web 应用、以及我们通过 API 或浏览器扩展提供的相关功能。
不适用于由第三方独立运营的服务（例如你自行开通的 Amazon / Shopee 卖家后台），
也不适用于我们已另行约定数据处理协议的客户数据委托处理场景（见第十一节）。

## 二、我们收集哪些信息、如何收集

我们仅收集为实现下述目的**所必需**的信息。按来源分为三类：

### 2.1 你主动提供的信息

| 类别 | 具体内容 | 是否必需 |
|---|---|---|
| 账号信息 | 邮箱地址、密码（仅以**不可逆哈希**形式存储，我们不持有明文）、昵称、角色 | 必需 |
| 团队与归属 | 所属账户/团队、成员邀请关系、成员角色 | 必需 |
| 店铺授权 | 你在连接 Amazon / Shopee 店铺时提供的卖家授权凭据（**加密存储**） | 使用相关功能时必需 |
| 支付信息 | 订阅套餐、账单记录、支付渠道返回的交易号（**我们不存储你的银行卡号/支付密码**，由支付机构处理） | 付费时必需 |
| 你上传的内容 | 商品图片、产品文档、FAQ/话术资料、通过对话提交的指令文本 | 使用相关功能时必需 |
| 声音素材 | 你为"语音克隆"功能提供的音色样本（需你**另行单独同意**，见第十节） | 使用该功能时必需 |

### 2.2 你使用服务时我们自动收集的信息

- **设备与日志**：IP 地址、浏览器类型与版本、操作系统、访问时间、请求路径与结果；
- **登录安全**：登录尝试记录（成功/失败、原因、IP、时间），用于风控与账号锁定；
- **审计日志**：对重要业务对象（成员、店铺、归属）的增删改操作记录，
  包含操作人、动作、目标与结果；
- **会话与记忆**：你与 AI Agent 的对话内容，以及 Agent 为保持多轮连续性而保存的
  会话状态（用于"记得上文"）。

### 2.3 来自第三方或由我们加工生成的信息

- **平台数据**：经你授权，通过 Amazon SP-API / Shopee Open Platform 获取的
  商品、报价、库存、订单、广告与评价数据；
- **AI 生成内容**：由大模型产生的文案/分析结论，以及由文生图、语音合成产生的
  图片与音频。

> **我们不收集**：生物识别信息、精确地理位置、通讯录、短信/通话记录、金融账户密码。
> 若未来新增任何数据类别，我们会更新本政策并（在依法需要时）重新取得你的同意。

## 三、我们如何使用这些信息

我们仅在下列目的与法律依据范围内使用收集的信息：

1. **提供与履行服务**（履行合同所必需）：账号与登录、店铺数据同步、AI 功能调用、
   结果展示与导出、订阅与账单管理；
2. **保障安全**（履行法定义务 / 保护重大合法权益）：账号防刷、异常登录拦截、
   操作审计与留存期清理；
3. **改进产品**（基于合法利益，且以去标识化/聚合形式进行）：功能使用统计、
   错误诊断、性能优化；
4. **与你就服务进行沟通**：服务通知、安全提醒、账单与到期提醒、
   以及在你同意的前提下的产品动态。

**我们不会**将你的个人信息用于自动化决策且对你有重大影响的情形；
若未来引入此类处理，我们会事先告知并提供拒绝/人工干预的途径。

## 四、我们如何共享、委托处理与对外提供

我们**不会出售**你的个人信息。仅在下列情形共享：

1. **受托处理者（子处理者）**：为运行服务而必需的第三方服务商，包括但不限于：

   | 用途 | 服务类别 | 说明 |
   |---|---|---|
   | 大模型推理 / 文本与向量嵌入 | 阿里云百炼（DashScope，Qwen 系列） | 对话、分析、文案生成、语义检索 |
   | 文生图 / 图像编辑 | 同上（图像生成模型） | 素材生成功能 |
   | 语音合成 / 语音克隆 | 同上（语音模型） | 语音播报与音色克隆功能 |
   | 平台数据接入 | Amazon SP-API、Shopee Open Platform | 经你授权拉取店铺数据 |
   | 在线支付 | 支付宝（Alipay） | 订阅收款与对账 |
   | 邮件发送 | 阿里云邮件推送（DirectMail） | 验证邮件、安全与账单通知 |
   | 对象存储 | **不使用第三方对象存储** —— 上传素材与生成结果落本机 `uploads/`，经服务自身 `/static` 提供 | 上传素材与生成结果的存储 |

   完整、现行的子处理者清单见 [`subprocessors.md`](./subprocessors.md)（对外发布时须将该文件发布为可公开访问的 URL），我们会在变更前通知你。
2. **法定情形**：依法律法规、司法/行政机关强制性要求而必须提供时；
3. **你的授权**：经你单独同意的其他情形。

**关于 AI 功能的重要提示**：为实现对话、分析、生成等能力，你提交的**指令文本**
以及**为实现该次指令所必需的上下文**（可能包含商品标题、评价正文等）会发送至
上述大模型服务商进行处理。请**不要**在对话中提交与业务无关的敏感个人信息。

## 五、跨境传输

**当前不涉及个人信息出境。** 本服务所选用的第三方服务（阿里云百炼 DashScope、
阿里云邮件推送 DirectMail、支付宝）均部署于**中华人民共和国境内**，个人信息在境内
处理与存储。若未来因更换服务商或调整部署而需要将个人信息传输至境外，我们将在传输前
履行法定程序（标准合同 / 安全评估 / 个人信息保护认证 之一），更新本政策，并向你告知
接收方与传输路径。

## 六、存储与留存

- **存储地点**：{{DATA_STORAGE_LOCATION}}。
- **留存期限**：我们按"实现目的所必需的最短时间"留存，并按下表执行；到期后删除或匿名化：

  | 数据类别 | 留存期 | 依据 |

  | 邮件一次性令牌 | 7 天（仅清已消费/已过期） | 安全 |
  | 业务数据（商品/订单/评价等） | 随账号存续；你可在功能内删除或申请删除 | 履行合同 |

## 七、我们如何保护信息

1. **加密**：店铺授权凭据等敏感字段采用对称加密后落库；传输采用 HTTPS。
2. **访问控制**：多租户隔离——你的数据按账户/店铺归属过滤，其他租户无法访问；
   后台能力对内部人员按最小权限授予。
3. **审计与监控**：关键写操作留痕；运行指标与告警覆盖接口错误率、依赖可用性、
   后台清理任务是否按时执行。
4. **备份**：数据库每日备份并做完整性校验与恢复演练。

尽管我们采取上述措施，互联网环境并非绝对安全。若发生个人信息安全事件，
我们将按法律要求及时以邮件/站内通知等方式告知你可能受到的影响及已采取的处置措施。

## 十、语音克隆的特别说明

"语音克隆"功能会处理你的**声音**（生物特征相关信息）。该功能**默认关闭**且
**必须经你单独、明确同意**后方可启用；启用前你需确认你已取得该音色权利人的授权。
你可随时在功能面板中删除已克隆的音色；删除后我们不再持有该音色样本。
**请勿**在未获授权的情况下克隆他人声音，或将克隆音色用于误导、欺诈或违法用途。
