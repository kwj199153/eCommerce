# 品牌标识与品牌色 · 第 373 轮定案

> 起点：**老板截图报「马卡龙主题的 logo 不是蓝色」**。
> 结论：那不是配色失误，是**层级搞错了** —— logo 底色取了 L2 主题主色。
> 本轮把「品牌标识」从一个跟着主题漂的装饰，变成一件**有唯一真源、有判据、改错会红**的资产，
> 并顺带落下一层更细的**L1/L2 适用判据**（见 §4）。

---

## 1. 根因（一句话）

```css
.logo-avatar { background: var(--primary); }   /* ← 改前：L2 主题主色 */
```

`--primary` 是 **L2 主题主色**，它的职责就是"该随主题变"（深底不提亮就不可读）。
而 logo 是 **L1 品牌资产**，定义就是"**不管在哪儿都是这个色**"。
⇒ 切到马卡龙档，标识跟着变成玫红 `#c33a76`。

eEducation 的解法（第 457 轮）：**`BRAND_VARS` 独立导出、不进任何主题表、注入 `:root`**。
本仓照搬，且是**结构上**分开 —— 不是"三档碰巧写成同一个值"（那种防不住下一次有人单独调某档）。

## 2. 标识怎么定下来的

### 2.1 参考图是**测绘**出来的，不是"照着描"

按「横向满幅 = 48 网格」归一后逐行扫白像素：

| 部件 | 参考图实测 | 结论 |
|---|---|---|
| 檐·上沿 | y=8.1，宽 24.6 | 平顶 + **大圆角**（半径 ≈3） |
| 檐·下摆 | y=15.0，宽 33.0 | 比上沿宽 **34%** —— 这就是"招"的形 |
| 檐·波浪 | 3 瓣，深 ≈2.5 | |
| 墙·笔画 | **2.1** | ★ 极细 |
| 笑脸·笔画 | **1.2** | ★ 更细 |
| 底色 | `#026745` | 绿 |

★★ **测绘直接给出一条硬结论：参考图是「40px+ 应用图标」口径，不能照描。**

| | 参考图笔画 | 缩到 16px 后 | 定稿改用 |
|---|---|---|---|
| 墙 | 2.1 | **0.700 px** | 3.4（= **1.133 px**） |
| 笑脸 | 1.2 | **0.400 px** | 3.6（= **1.200 px**） |

0.7px 和 0.4px 在屏幕上**直接消失**。所以只能**保形加粗**（形不变、笔画按 16px 反推）。
这是两栏数字不同的**唯一**原因。

### 2.2 五轮迭代，4 个草稿系列

| 轮 | 方向 | 结果 |
|---|---|---|
| 1 | 檐/箱/袋/门 14 形 | 16px 糊掉 8 个 ⇒ 得出「**只能有一个连体形，元素间距 ≥10 单位**」 |
| 2-3 | 檐斗系 + 购物袋系 | 购物袋 36px 最像；但 16px 下**双提带必然粘连**（间距只剩 3.3px） |
| 4-5 | 店面（檐 + 壁） | **J2 门楣门洞** 是唯一 16px + 36px 双过的形 |
| 6（本轮） | 按参考图加**大圆角 + 3 瓣波浪 + 笑脸** | 定稿 **O6** |

★ 过程中最值钱的一条：**同一个比例，只差圆角，语义完全不同**。
第一版檐画成**尖角梯形** ⇒ 读成「屋顶」；改成半径 ≈3 的**圆角** ⇒ 才读成「店招」。
这一处比所有尺寸微调都关键。

### 2.4 三处落点与「严格子集」关系

| 落点 | 形 | 尺寸 |
|---|---|---|
| `components/BrandMark.vue`（侧栏 36px / 登录 48px） | **O6 含笑脸** | ≥20px 都好看 |
| `frontend/public/favicon.svg` | **O3 无笑脸** | 16px |
| `site/assets/favicon.svg` | **O3 无笑脸**（与上一条**逐字相同**） | 16px |

★ **为什么 favicon 少一条不算"两份实现"**：它是**删一条 path 的严格子集**，

是**结构性下限**，不是选值问题。≥20px 一律保笑脸。

## 3. L1 / L2 / L3 分层（延续 r372，本轮**细化了一层**）

```
L1 品牌层（产品色）—— 与主题无关 ⇒ 独立 BRAND_VARS，注入 :root（不带 [data-theme]）
   --brand #4f46e5 · --brand-ink #2b20df · --brand-lift #c2bff8 · --brand-wash #edecfe
   ▲ 与官网 site/assets/style.css 的 --brand* 逐字一致（两站同一个品牌）

L2 主题层（主题主色）—— 三张表，注入 html[data-theme="x"]
   --primary   light #4f46e5 · dark #756eea · macaron #c33a76

L3 情境强调色 —— --accent-pink 等，各档可有不同值
```

### ★★ 本轮新增的适用判据（比 r372 更细一层）

> **L1 适用于「自成一体的块」**（对比度由块**内部**保证，与页面底无关）；
> **L2 适用于「直接坐在页面底上的东西」**（必须随主题提亮）。

| 对象 | 取哪层 | 为什么 |
|---|---|---|
| 标识方块（底 + 白笔画） | **L1** | 白笔画对 `#2b20df` = **8.84:1**，与页面底无关 ⇒ 三档都清晰 |
| 登录页标题（28px 文字，坐在卡片底上） | **L2** | 深档下 L1 靛蓝对深底只有 **2.08:1**（28px 大字 AA 要 3:1，连它都不到）；L2 深档 `#756eea` = **4.06:1** ✅ |
| 侧栏 `.logo-title`「店秘书」 | 一直是 `--text-primary` | 本来就对 |

★★ **这条判据是真机截图抓出来的**，不是想出来的 —— 见 §6.1。

## 6. ★ 只有"做全了"才会撞出来的四件事

### 6.1 真机截图抓出**判据的期望值写反了**

我第一版把登录页标题也切到 L1（"标题 + 标识是一个品牌区块"），判据 B8c 写成
「`.logo h1` **不得**取 `var(--primary)`」。**30 条全绿**。

然后真机截图：深色档下标题「跨境电商AI SaaS」**明显发暗** ——
`#2b20df` 对深底只有 **2.08:1**，连大字号的 3:1 都不到。

⇒ **判据全绿但界面是错的**：不是判据没生效，是**期望值本身写错了**。
改判据方向（`--primary` 必须取、`--brand-ink` 不许取），并把 §3 那条适用判据写进注释。

> 教训：**判据只能保证"代码 = 你以为的东西"，保证不了"你以为的是对的"。**
> 一行 `getComputedStyle` 比十条静态判据更能戳穿错误期望。

### 6.2 消费者门禁缺了"第 4 个定义源"

`scripts/check-theme-var-refs.py` 会断言「组件里 `var(--x)` 的 x **必须真实存在**」，
它收集定义的来源只有 4 处：`LIGHT_VARS` / `DARK_VARS` / `App.vue :root` / `index.html` 兜底。

新增 `BRAND_VARS` 后，`.logo-avatar { background: var(--brand-ink) }` 会**被判成"未定义"**——
一条**假红**。改完定义全集 133 → **137**（正好 +4 = BRAND_VARS 四键）。

> 教训：**「加一个变量」是生产者的事，但"谁认得它"是消费者的事** —— 两边都要动。

### 6.3 `index.html` 引的 favicon **文件不存在**，而真图标**零引用**

- `index.html` 一直引 `/vite.svg` —— `public/` 下**没有这个文件** ⇒ **404**，tab 上是浏览器默认图标；
- `public/favicon.svg`（9.5 KB 的紫色闪电）**存在但从未被引用**（死资源）。

两处都不对，且都**没人发现** —— 因为没有判据看 tab。
⇒ 本轮 B8d/B8e 把这两条都钉住了。

### 6.4 变异脚本的锚点**命中了注释**

变异 N1（改檐的 `d`）报了"逃逸"。查下去：锚点 `M11.7 8.4 H36.3` 在 `BrandMark.vue` 里
出现了**两次** —— 文件头注释里也写了那条几何。`String.replace` 只改**第一处** ⇒
改到了注释上，**几何其实没动**，于是"逃逸"是假的（判据没洞，是脚本锚点错了）。

> 教训：这与判据铁律「必须剥注释再判」是**同一枚硬币的两面** ——
> **锚点要带语法上下文**（`d="M11.7 …`），光靠几何串本身不够。

## 10. 一句话教训

> **「判据全绿」和「东西是对的」是两件事。**
>
> 本轮最值钱的三个发现都不在绿色里：**深档发暗**（真机截图抓到，静态 30 条全绿）、
> **favicon 一直 404**（没人看 tab）、**`var(--brand-ink)` 会被判成未定义**（消费者的定义源少一个）。
> ⑨ 它们共同的形态是 —— **一切看起来都对，只是没人在真实场景里看过一眼**。
>
> 所以本轮的门禁不止"读源码"：还真的**加载模块跑一次**（③）、真的**开浏览器切三档**（④）。
> 判据的价值不在于它有多少条，而在于**它替你看了哪一眼**。
