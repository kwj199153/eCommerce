# 能力广场入口从「菜单最后一项」挪到「数字员工」标题行右端（第 376 轮）

> 指令原文：「能力仓库位置改到数字员工的右侧红框处」（附侧栏截图，红框 = 「数字员工」标题行的右端）。

## 1. 为什么要挪（不只是"换个位置"）

原位置是 `<a-menu>` 里的**最后一项**，紧跟在「运营复盘师」下面 —— 于是它和上面 7 个员工
长得一模一样（同样的行高、同样的缩进、同样的图标位），被读成「第八个员工」。

而它根本不是员工：它是**陈列面入口**（看每个员工现在会什么），与整个分组平级。
放在标题行右端才符合它的语义，顺带菜单少一行 34px。

## 3. 三个不显然的决定

### ① 折叠态（80px 图标条）**隐藏**这个按钮

实测：折叠后标题行可用宽度只剩 **48px**（80 − padding 16×2），塞进 22px 按钮后浏览器把
「数字员工」压成两行并被裁掉下半截，按钮自身也被挤到 **14px** 宽
（截图 `.workbuddy/probes/out/plaza-entry-collapsed.png`）。

⇒ `.ant-layout-sider-collapsed .sidebar-section-title .section-action { display: none }`。
折叠态本来就是"只留图标"的形态，而这个按钮没有独立图标位（它住在标题行里）；
点汉堡展开即可看到 —— 那才是它的语义位置。

### ② 常态色取 `--text-secondary`，不是 `--text-tertiary`

它现在是这一组**唯一**的能力广场入口（菜单里那项已删）。用 tertiary 会和标题文字糊成一片，
在浅底上几乎读不出"这里有个能点的东西"。

### ③ 焦点环用 `--brand`，不是 `--brand-primary`

本仓**没有** `--brand-primary` 这个变量（四档品牌变量是 `--brand` / `--brand-ink` /
`--brand-lift` / `--brand-wash`）。写 `var(--brand-primary, #0958d9)` 会让 fallback **恒生效**，
等于把焦点环钉在已退役的旧蓝上，并且是一处硬编码色值。
