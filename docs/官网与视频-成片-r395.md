## 5. 要改的时候怎么做

```bash
# 只改一句台词（比如 05 段的口播）
#   1. 改 segments.json 里 05-service 的 lines[].say / .html
#   2. 重新配音（只有这一段）
python .workbuddy/tools/video/vid_tts_seg.py 05-service
#   3. 重渲 + 重编 + 重拼
node   .workbuddy/tools/video/vid_seg.cjs 05-service
python .workbuddy/tools/video/vid_compose.py 05-service   # 自动 concat
```

⚠️ 重渲前把该段 `frames/` **改名挪开**（`mv frames frames.old`）—— 本机安全删除守卫
对"一轮内删 >50 文件"直接拒，而渲染器会先逐个 `unlink` 旧帧。

⚠️ 改 `voice` / `rate` / `pad` / `fps` **必须全片重出**：concat 用 `-c copy`，
参数不一致会音画不同步或色差。

## 6. 还没做的（明说，别当已完成）

- **没有 BGM、没有转场特效**：七段是硬切。要转场得在 `vid_compose.py` 里加 `xfade`，
  但它要求重新编码整片（不能用 `-c copy`）。
- **没有竖屏版**：简历/朋友圈若需要 9:16，得另出一版（`size` 改 `[1080,1920]`，
  每段的运镜都要重新算边界，不是简单裁切）。
- **英文版没有**：TTS 换 `en-US-*` + 台词改英文即可，但字幕排版要重调。
