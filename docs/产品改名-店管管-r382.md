### 两处「不改就等于没改」的联动（本轮的关键）

1. **`.env` 是第二真源**：`backend/.env` 里写着 `APP_NAME=CrossBorder-AI-SaaS`，它**覆盖**代码默认值。
   只改 `core/config.py:127` 时，实测运行时仍是 `APP_NAME= CrossBorder-AI-SaaS`。
   ⇒ 必须同时改 `.env` 与 `.env.example`。
2. **契约门禁钉着旧名**：`backend/scripts/check_openapi_contract.py::DEFAULT_FORCED_ENV["APP_NAME"]`
   与快照 `backend/docs/api/openapi.json` 的 `info.title` 都是旧名，改了 config 不改这两处，
   `--check` 直接红。⇒ 常量同步改 + `--write` 重导出快照（238 路径 / 151 schema）。
3. **发件人别名是另一个字段**：`aliyun_dm_from_alias` 原文是 `跨境电商AI`（不带 SaaS），
   第一轮批量规则没命中，是二次扫描才捞出来的 —— 它决定客户收邮件时看到的发件人名。

## 六、第 383 轮：pad 端补漏（`productName` 才是图标名的真源）

### 现象与根因

现象：应用**里面**是「店管管」，可平板桌面图标下、最近任务卡片上写着 `ShopButler`。

| # | 根因 | 细节 |
|---|---|---|
| 1 | 382 轮只改了窗口标题 | `app.windows[0].title` 只影响 Windows 标题栏；安卓图标名读的是 `productName` 派生的 `strings.xml` |
| 2 | 派生物不会自动回写 | `src-tauri/gen/android/.../values/strings.xml` 的 `app_name` / `main_activity_title` 来自 `productName`，但 `gen/` 被 `.gitignore` 忽略、`productName` 改了它**不会**跟着变 ⇒ 必须手改 |
| 3 | 证据 | `aapt2 dump badging` 旧包：`application-label:'ShopButler'`，且 60+ 个语言变体全是同名 |

### 顺带修的一条硬伤：壳里后端地址是明文 http

8090 只讲 TLS，发明文请求会被 nginx 回 `400 The plain HTTP request was sent to HTTPS port`
⇒ **按旧配置打出的包，装上去每条请求都 400**，表现就是「登录页一直账号或密码错误」。

- 证书是 **Let's Encrypt 的 IP 证书**（`notBefore Oct 18` / `notAfter Oct 24`，short-lived 6 天），
  系统根链默认信任：`curl` **不带 `-k`** 也返回 200 ⇒ Android WebView 同样能过校验，
  release 包不再需要 `usesCleartextTraffic`。
- 包内二进制复核：`https://111.229.201.117:8090` 命中 1 处，`http://` 命中 **0** 处。
- ⚠️ 该证书几天就到期：续期一断，壳里所有请求会集体失败，症状与「密码错」无法区分 —— 排查先看证书。
