## 5. ★★ 产品侧验收的特有陷阱：SPA 兜底会把「缺文件」返回成 200

实测（现取）：

```
GET /vite.svg   →  HTTP/1.1 200 OK        ← 状态码骗人
                   Content-Type: text/html ← 真相：这是 index.html（3717 B）
```

SPA 兜底接住了**任意**未知路径 ⇒ **只看状态码的验收在产品侧会全部通过**。
⇒ 验收必须带 `Content-Type` / 内容指纹。建议最小集：

| 路径 | 期望 |
|---|---|
| `/` | 200 · `text/html` |
| `/assets/index-<hash>.js` | 200 · `application/javascript` · **sha256 与交付件一致** |
| `/favicon.svg` | 200 · `image/svg+xml`（新版 1864 B） |
| `/api/v1/stores` | 200（反代没被弄坏） |
| `/shop/definitely-not-a-page` | **404**（官网侧仍不许兜底） |
