⑤ 配色分层（照 eEducation 456/457 的口径）

标识的底色必须住在 L1 品牌层，不能取 L2 主题色 —— 这就是你截图里 logo 变玫红的根因。

L1 品牌层（产品色）—— 与主题无关，独立 BRAND_VARS ⇒ 注入 :root（不带 [data-theme]）
   --brand       #4f46e5   品牌正色（官网主色 / 强调）
   --brand-ink   #2b20df   ★ 标识底色（本稿的瓦片底）
   --brand-lift  #c2bff8   浅边 / 分隔
   --brand-wash  #edecfe   浅底 / 悬停底
L2 主题层（主题主色）—— 三张表，注入 html[data-theme="x"]
   --primary     light #4f46e5 · dark #756eea · macaron #c33a76
L3 情境强调色 —— 图表 / 状态，另表

✗ 现在产品站 logo 用的是：.logo-avatar { background: var(--primary) }  ← L2
✓ 该改成：            .logo-avatar { background: var(--brand-ink) }  ← L1
