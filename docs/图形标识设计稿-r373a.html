图形标识设计稿 —— 4 个候选，请你挑一个

起点是你截图里那个问题：马卡龙主题下，侧栏左上角的 logo 变成了玫红（#c33a76）。
根因不是颜色选错了，是 logo 吃的是「主题主色」而不是「品牌色」 —— 它本来就不该跟着主题变。这份稿子同时回答两件事： ① 标识长什么样；② 颜色怎么分层（照 eEducation 第 456/457 轮那套流程）。

① 四个候选

全部画在 48×48 网格、单色笔画（currentColor）、零字体依赖。 下方是它们在真实方块里的样子（96px 展示，几何自带内边距 ⇒ 不用再调边距）。

④ 配色怎么分层（照 eEducation 456/457 的流程）

一句话原则：换主题它该不该变？该变 ⇒ 主题色；不该变 ⇒ 品牌色。 这条判据在 eEducation 是踩过坑才立起来的 —— 那边原来把「品牌色」和「主题色」 用同一个变量（--primary）表达，结果 logo 在 3 个主题下有 3 种底色。

L1 品牌层（产品色） —— 与主题无关，写在独立的 BRAND_VARS 里，注入 :root（不带 [data-theme]） ├── --brand #4f46e5 品牌色本体（深底强调 / 大字号点缀） ├── --brand-ink #2b20df 标识方块底 ← 本轮 logo 改用的就是它（白字 8.84:1） ├── --brand-lift #c2bff8 深色带上的强调（对深带底 10.07:1） └── --brand-wash #edecfe 极浅靛底（eyebrow / tag）= 产品 --info-bg ▲ │ 结构上的隔离：这三张表里根本没有 --brand* 这两个字 │ ⇒ 连"改一档"这个动作都不存在（不只是"三档碰巧同值"） ▼ L2 主题层（主题主色） —— 写在 LIGHT_VARS / DARK_VARS / MACARON_VARS 三张表里，注入 html[data-theme="x"] ├── --primary light #4f46e5 · dark #756eea · macaron #c33a76 ← UI 交互色（按钮/链接/选中态） ├── --primary-hover 三档各一（AA 已算过） └── --info-bg / --info-border / --bg-active-* … ← 派生态，跟着 --primary 走 L3 情境层（如营销页的视差带、报告纸） └── 只在单个页面成立，不进主题表、也不进 BRAND_VARS

为什么 --brand-ink 取 #2b20df 而不是 --brand 本身

值色相白字对比度AA(4.5)说明
#2b20df243.46°8.84:1✅✅ 与 --brand 同色相（Δh 0.06°），只深一档 ⇒ 小尺寸更锐、更跳
#4f46e5243.40°6.29:1✅ 品牌色本体。也过 AA，但它还要兼任"深底强调字"，两个角色分开更好

★ 这两个值不是我编的：官网 site/assets/style.css 上轮已经定了 --brand:#4f46e5 / --brand-ink:#2b20df。 本轮是让产品站与官网逐字对齐 —— 之前产品站根本没有这两个变量（这是根因）。 全部数字由 .workbuddy/probes/tools/brand-color-facts.py 现算，不手写。

⑥ 落选方案与理由（供你判断我是否看走眼）

我做了 5 轮共 40+ 个草稿，每一轮都用真实像素渲染后淘汰。淘汰原因基本只有两类： 小尺寸糊、语义读不出来。下面按死因分组。

檐 台 斗（多个）
店铺遮阳篷的"正经画法"（檐 + 篷身 + 台）：16px 糊。48 网格里三层结构的间距只剩 2px 左右，笔画本身就有 2px ⇒ 必然粘。
三根柱子
承接官网现状的"增长柱"：16px 三根柱粘成一块（间距 1.3px）。这条路只在 ≥32px 成立。
箱 + 折线上升
电商感最好的组合之一，但 16px 下折线成一团；箱 + 单一斜线稍好，但看着像"斜杠"。
袋 + 双提带
36px 下确实最像购物袋（我一度以为定这个了），但 16px 两根提带必然粘连 —— 间距只有 3.3px。现实购物袋的两根绳，在 favicon 尺寸上不存在。
袋 + 闭合提手
16px 能活，但 36px 读成锁（提手与袋身形成锁梁）。这是 C 候选的已知缺陷，仍保留给你做对比。
菱形 / 圆点 / 印鉴 / 伞
小尺寸干净，但没有可读的语义 —— 换成任何别的产品也成立，等于没标识。
汉字符号化
用「店」字自绘或 <text>：前者笔画太多糊成一团，后者要靠访客的系统字体渲染 ⇒ 同一个标识在 Windows / macOS / 安卓长得不一样，16px 更糊（这正是 eEducation 当年否掉「学」字的原因）。
加"AI 火花"/ 点
想表达"AI"，但在 16px 下糊成一个脏点。eEducation 的 R4 也是同样的死因。
A1 / A2 / A3 / B1
A（门楣）的比例变体，都已渲染：A3（窄门）最像"带檐的门"，A2（粗檐）最稳；当前 A 是这三者的折中。B1（大张角篷）16px 变成"人"字，已淘汰。
